# Retail Data Analysis

**Objective**  
Perform sales analysis and customer segmentation for retail data.

**What’s Inside**  
- Sales trend visualizations by product, region, season  
- Customer segmentation using RFM analysis or clustering  
- KPI dashboards: revenue, orders, average basket size

**Stack**  
Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn, Jupyter

# Retail Data Analysis

## Project Overview
A deep dive into customer transactions to identify purchasing trends, segment customers, and evaluate product performance.

##  Technologies Used
- Python, Pandas, NumPy
- Scikit-learn
- AWS S3 for data storage
- AWS Redshift for data warehousing
- Plotly for interactive plots

##  Key Features
- ✅ Analyzes customer buying behavior  
- ✅ Performs RFM segmentation  
- ✅ Builds visual dashboards  
- ✅ Loads outputs into AWS Redshift  
- ✅ Uses S3 for intermediate data layers

## Outcome
Demonstrates retail analytics, customer segmentation, and cloud-based reporting pipelines.
